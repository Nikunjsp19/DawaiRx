DawaiRx UI Test Helper

Open browser console and test these scenarios:

  1. Go to http://127.0.0.1:8000/login
  2. Login with test credentials
  3. Go to "New Report"
  4. Fill Step 1 (dates)
  5. Fill Step 2 (report name)
  6. Step 3: Upload files and click "Generate Report"
  7. Check console for errors
  8. Go to Dashboard and click on a report
  9. Check if report displays correctly

Common Issues to Check:

  • JavaScript errors in console
  • Network errors (401, 403, 500)
  • Missing DOM elements
  • Results not displaying
  • Report table not showing
